Aplicando tecnica de codificacion segun el modelo a utilizar¶

Explicaciones¶

  1. ¿Qué modelo vamos a usar? Random Forest (Bosque Aleatorio).¿Por qué? Es un modelo muy robusto para problemas de clasificación binaria (como predecir True/False). A diferencia de la regresión logística, Random Forest no asume relaciones lineales, maneja de forma excelente los valores atípicos (outliers) y no requiere que las variables numéricas (como RoomService o FoodCourt) estén estrictamente normalizadas o estandarizadas, aunque en tu plan de proyecto contemplan hacerlo.

  2. ¿Qué técnica de codificación aplicar? Dado que hay varias columnas categóricas (HomePlanet, CryoSleep, Cabin, Destination, VIP), la estrategia de codificación ideal para prepararlas para Random Forest o Regresión Logística es una combinación de técnicas:

Mapeo Binario (Binarización): Para variables que solo tienen dos estados como CryoSleep (dormido o no), VIP (paga servicios especiales o no) y tu variable objetivo Transported. Consiste en transformar True a 1 y False a 0.

One-Hot Encoding (Variables Dummy): Para variables categóricas nominales sin un orden específico y con pocas categorías, como HomePlanet y Destination. Esto crea una columna nueva de ceros y unos para cada planeta o destino.

Transformación y extracción (Alta cardinalidad): Variables como Cabin (número de cabina, cubierta y lado), Name (nombres y apellidos) y PassengerId no deben codificarse directamente porque tienen demasiados valores únicos.

# 1. Binarización de variables booleanas
bool_cols = ['CryoSleep', 'VIP', 'Transported']
for col in bool_cols:
    if col in df.columns:
        df[col] = df[col].astype(int) # Convierte True/False a 1/0

# 2. Extracción de datos de la cabina
if 'Cabin' in df.columns:
    df[['Deck', 'Num', 'Side']] = df['Cabin'].str.split('/', expand=True)
    df = df.drop(columns=['Cabin', 'Num'], errors='ignore')
else:
    print("Warning: 'Cabin' column not found, assuming 'Deck' and 'Side' were already extracted or not applicable.")

# 3. Eliminar variables que no codificaremos por su alta cardinalidad
# Nos aseguramos de eliminar PassengerId y Name
df = df.drop(columns=['PassengerId', 'Name'], errors='ignore')

# 4. One-Hot Encoding para las variables nominales (HomePlanet, Destination, Deck, Side)
categorical_cols = ['HomePlanet', 'Destination', 'Deck', 'Side']
actual_categorical_cols = [col for col in categorical_cols if col in df.columns]
df_encoded = pd.get_dummies(df, columns=actual_categorical_cols, drop_first=True, dtype=int)

2. Escalado o normalización de variables numéricas¶

  • Analizar si el modelo es sensible a la escala (KNN, SVM, regresión, redes).
  • Elegir el método adecuado:
    • Min-Max Scaling ajusta los valores entre 0 y 1.
    • Standard Scaling (Estandarización): convierte los valores a media 0 y desviación estándar 1.
    • Robust Scaling usa la mediana y el rango intercuartílico (útil si hay outliers).
