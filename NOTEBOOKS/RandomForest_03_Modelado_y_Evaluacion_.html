1. Selección del tipo de modelo¶

  • Determinar si el problema es de clasificación, regresión o agrupamiento.
  • Elegir los algoritmos adecuados según el tipo de problema y la naturaleza de los datos. Ejemplos:
    • Clasificación: Regresión logística, Árboles de decisión, Random Forest, SVM, Redes neuronales.
    • Regresión: Regresión lineal, Random Forest Regressor, XGBoost, Redes neuronales.
    • Agrupamiento: K-Means, DBSCAN, Hierarchical Clustering

Después de un proceso de análisis en grupo, hemos determinado que nuestro reto del Spaceship Titan es un problema de clasificación binaria supervisada porque la variable objetivo transported, es categórica booleana y busca determinar a que categoría pertenece cada pasajero. Consideramos que es un reto de supervisión porque contamos con el conjunto de datos de entrenamiento que contiene ya la variable respuesta conocida para entrenar el modelo.

Por último, es binaria dado a que lo que nuestros modelos buscarán predecir es ver si es verdadero o falso la variable objetivo.

df = pd.read_csv("data_for_modeling.csv")
df_limpio = df.copy()

# Separar variables predictoras (X) y objetivo (y)

# Definimos el grid específico para Random Forest
parametros_grid_rf = {
    'n_estimators': [100, 200],
    'max_depth': [4, 6, 8, 10],
    'min_samples_split': [10, 20, 30],
    'min_samples_leaf': [5, 10, 20]
}

# Configurar el GridSearchCV
grid_search_rf = GridSearchCV(
    estimator=RandomForestClassifier(random_state=42),
    param_grid=parametros_grid_rf,
    cv=5,
    scoring='accuracy',
    n_jobs=-1,
    verbose=1 # Mostrará el progreso (ej. "Fitting 5 folds for each of 36 candidates")
)

# Entrenar el Grid Search
grid_search_rf.fit(X_train, y_train)

# Guardar el modelo optimizado
mejor_modelo_rf = grid_search_rf.best_estimator_
joblib.dump(mejor_modelo_rf, 'mejor_modelo_random_forest.pkl')

print("\n--- Resultados de la Optimización ---")
print(f"Mejores Parámetros Encontrados: {grid_search_rf.best_params_}")
print(f"Mejor Exactitud durante Validación Cruzada: {grid_search_rf.best_score_:.4f}")

from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score, roc_auc_score, confusion_matrix, roc_curve
import matplotlib.pyplot as plt
import seaborn as sns

# --- 1. Generar predicciones y probabilidades para Train y Test ---
y_pred_train_rf = mejor_modelo_rf.predict(X_train)
y_pred_test_rf = mejor_modelo_rf.predict(X_test)

# predict_proba para la Curva ROC (probabilidad de ser clase 1)
y_prob_train_rf = mejor_modelo_rf.predict_proba(X_train)[:, 1]
y_prob_test_rf = mejor_modelo_rf.predict_proba(X_test)[:, 1]

# --- 2. Cálculo de métricas principales en Test ---
acc_rf = accuracy_score(y_test, y_pred_test_rf)
prec_rf = precision_score(y_test, y_pred_test_rf)
rec_rf = recall_score(y_test, y_pred_test_rf)
f1_rf = f1_score(y_test, y_pred_test_rf)
roc_auc_rf = roc_auc_score(y_test, y_prob_test_rf)

print("--- Evaluación en Conjunto de Prueba (Random Forest Optimizado) ---")
print(f"Accuracy:  {acc_rf:.4f}")
print(f"Precision: {prec_rf:.4f}")
print(f"Recall:    {rec_rf:.4f}")
print(f"F1-Score:  {f1_rf:.4f}")
print(f"ROC-AUC:   {roc_auc_rf:.4f}\n")

# --- 3. Análisis de Sesgo y Varianza (Underfitting / Overfitting) ---
acc_train_rf = accuracy_score(y_train, y_pred_train_rf)
diferencia_rf = acc_train_rf - acc_rf

print("--- Análisis de Sesgo y Varianza ---")
print(f"Rendimiento en Entrenamiento (Train): {acc_train_rf:.4f}")
print(f"Rendimiento en Prueba (Test):         {acc_rf:.4f}")
print(f"Diferencia (Train - Test):            {diferencia_rf:.4f}\n")

if diferencia_rf > 0.05:
    print("Diagnóstico: OVERFITTING (Alta Varianza). El modelo aún memoriza un poco, podrías reducir 'max_depth' o aumentar 'min_samples_leaf'.")
elif acc_train_rf < 0.70 and acc_rf < 0.70:
    print("Diagnóstico: UNDERFITTING (Alto Sesgo). El modelo es demasiado simple.")
else:
    print("Diagnóstico: BALANCE ADECUADO. El modelo generaliza de forma excelente.")
