1. Selección del tipo de modelo¶

  • Determinar si el problema es de clasificación, regresión o agrupamiento.
  • Elegir los algoritmos adecuados según el tipo de problema y la naturaleza de los datos. Ejemplos:
    • Clasificación: Regresión logística, Árboles de decisión, Random Forest, SVM, Redes neuronales.
    • Regresión: Regresión lineal, Random Forest Regressor, XGBoost, Redes neuronales.
    • Agrupamiento: K-Means, DBSCAN, Hierarchical Clustering

Después de un proceso de análisis en grupo, hemos determinado que nuestro reto del Spaceship Titan es un problema de clasificación binaria supervisada porque la variable objetivo transported, es categórica booleana y busca determinar a que categoría pertenece cada pasajero. Consideramos que es un reto de supervisión porque contamos con el conjunto de datos de entrenamiento que contiene ya la variable respuesta conocida para entrenar el modelo.

Por último, es binaria dado a que lo que nuestros modelos buscarán predecir es ver si es verdadero o falso la variable objetivo.

df = pd.read_csv("data_for_modeling.csv")
df_limpio = df.copy()

# Escalado para la regresión logística

# stratify=y asegura que la proporción de clases se mantenga en Train y Test.

    X, y,
    test_size=0.2,
    random_state=42,
    stratify=y
)


scaler = StandardScaler()

# Ajustar el escale para los datos de train
X_train= scaler.fit_transform(X_train)

# Aplicar la misma transformación al test

from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score, confusion_matrix
import matplotlib.pyplot as plt
import seaborn as sns

# 1. Inicializar el modelo
# - random_state=42: Asegura reproducibilidad en el algoritmo.
# - max_iter=1000: Le da suficiente tiempo al modelo para encontrar la mejor solución matemática.
modelo_logistico = LogisticRegression(random_state=42, max_iter=1000)

# 2. Entrenar el modelo con los datos de entrenamiento escalados
print("Entrenando Regresión Logística...")
modelo_logistico.fit(X_train, y_train)

# 3. Hacer predicciones sobre los datos de prueba
y_pred = modelo_logistico.predict(X_test)

# 4. Calcular métricas de evaluación
accuracy = accuracy_score(y_test, y_pred)
precision = precision_score(y_test, y_pred)
recall = recall_score(y_test, y_pred)
f1 = f1_score(y_test, y_pred)

print("\n--- Resultados del Modelo Base ---")
print(f"Exactitud (Accuracy): {accuracy:.4f}")
print(f"Precisión (Precision): {precision:.4f}")
print(f"Sensibilidad (Recall): {recall:.4f}")
print(f"Puntuación F1 (F1-Score): {f1:.4f}")

# 5. Visualizar la Matriz de Confusión
cm = confusion_matrix(y_test, y_pred)

plt.figure(figsize=(6, 4))
# Matriz de confusión
sns.heatmap(cm, annot=True, fmt='d', cmap='Blues',
            xticklabels=['No Transportado (0)', 'Transportado (1)'],

plt.title('Matriz de Confusión - Regresión Logística Base')

from sklearn.model_selection import cross_val_score, GridSearchCV
import numpy as np

# --- 1. Validación Cruzada (Cross-Validation) ---
print("Aplicando Validación Cruzada...")
# Dividimos los datos de entrenamiento en 5 partes (folds)
puntuaciones_cv = cross_val_score(modelo_logistico, X_train, y_train, cv=5, scoring='accuracy')

print(f"Exactitud en cada partición: {puntuaciones_cv}")
print(f"Exactitud Media: {puntuaciones_cv.mean():.4f}")
print(f"Desviación Estándar (menor es mejor): {puntuaciones_cv.std():.4f}")


# --- 2. Ajuste de Hiperparámetros con Grid Search ---
print("\nIniciando Grid Search para optimización de hiperparámetros...")

# Definimos el "grid" o cuadrícula de parámetros a explorar
parametros_grid = {
    'C': [0.01, 0.1, 1, 10, 100],          # Controla la fuerza de la regularización (menor = más fuerte)
    'penalty': ['l1', 'l2'],               # Tipo de penalización matemática
    'solver': ['liblinear', 'saga']        # Algoritmos de optimización compatibles con l1 y l2
}

# Configurar el GridSearchCV
grid_search = GridSearchCV(
    estimator=LogisticRegression(random_state=42, max_iter=2000),
    param_grid=parametros_grid,
    cv=5,                   # Validación cruzada de 5 particiones interna
    scoring='accuracy',     # Queremos maximizar la exactitud
    n_jobs=-1,              # Usa todos los núcleos del procesador para ir más rápido
    verbose=1               # Muestra el progreso en la consola
)

# Entrenar el Grid Search con los datos
grid_search.fit(X_train, y_train)

# Resultados del mejor modelo
print("\n--- Resultados de la Optimización ---")
print(f"Mejores Parámetros Encontrados: {grid_search.best_params_}")
print(f"Mejor Exactitud durante Validación Cruzada: {grid_search.best_score_:.4f}")

#  Modelo optimizado
mejor_modelo_logistico = grid_search.best_estimator_

acc_train_log = accuracy_score(y_train, y_pred_train_log)
diferencia_log = acc_train_log - acc_log

    print("Diagnóstico: OVERFITTING. El modelo se sobreajustó a los datos de entrenamiento.")
